Cihazlarınız Arasında Güvenli Eşitleme

YDevDesk hiçbir merkezi sunucu işletmez ve kişisel verilerinizi toplamaz. Çalışma alanlarınız, ayarlarınız ve token analitiğiniz cihazınızdan çıkmadan şifrelenir ve yalnızca sizin kendi GitHub hesabınız üzerinden eşitlenir.

Nasıl Çalışır?

  • Yalnızca Gist İzni (OAuth Device Flow): Ayarlar → Senkronizasyon sekmesinden GitHub ile Bağlan dediğinizde tarayıcıda tek kullanımlık bir kod onaylarsınız. Uygulama yalnızca size özel bir Gist oluşturmak için gist izni ister; kod repolarınıza, e-posta adresinize veya özel projelerinize erişmez.
  • Uçtan Uca Şifreleme (AES-256-GCM): İlk cihazda otomatik olarak YDEV-... biçiminde bir Sync Anahtarı oluşturulur. Tüm veriler cihazınızdan çıkmadan önce yerel olarak şifrelenir. İkinci cihazda bu anahtar girilmeden veriler okunamaz.
  • Otomatik ve Hafif Eşitleme: Uygulama arka planda yalnızca değişiklik olup olmadığını kontrol eder (ETag). Değişiklik yoksa veri indirilmez ve API kotanız tüketilmez.

Gizlilik ve Veri Güvenliği Aydınlatması

  • Veri Toplama ve Üçüncü Taraf Paylaşımı Yoktur: YDevDesk geliştiricisi tarafından işletilen herhangi bir bulut veritabanı, analitik sunucusu veya takip aracı bulunmaz. Hiçbir veriniz geliştiriciye veya üçüncü taraflara iletilmez.
  • GitHub Hesabı Neden Kullanılır? Ayrı bir YDevDesk hesabı açmanıza ve şifre yönetmenize gerek kalmaması için yalnızca sizin kontrolünüzdeki GitHub hesabınız kişisel depolama alanı (Secret Gist) olarak kullanılır.
  • Yerel Anahtar Sahipliği: GitHub erişim belirteciniz ve şifreleme anahtarınız yalnızca kendi cihazınızda, işletim sistemi tarafından korunan özel izinli (0600) yerel dosyada saklanır; başka hiçbir yere gönderilmez.
  • İstediğiniz An Silme ve İptal: Uygulama içinden Bağlantıyı Kes diyerek yerel yetkiyi kaldırabilir, GitHub hesabınızdaki Gist kaydını silerek tüm eşitleme verilerinizi kalıcı olarak yok edebilirsiniz.

✓ Senkronize Edilenler

  • Hızlı komutlar (quick_actions)
  • Terminal şablonları (terminal_presets)
  • Modül ve bildirim tercihleri
  • Kayıtlı çalışma alanları (workspaces)
  • Oturum sabitleme ve özel isimler (session_prefs)
  • Cihaz bazlı token & maliyet özeti (tüm cihazlar toplanır)
  • Diğer cihazlardaki son oturumların özeti (cihaz rozeti ile)
  • İsteğe bağlı: Panel düzeni (layout)

✕ Senkronize Edilmeyenler (Gizlilik)

  • projects-root (OS'e özel klasör yolları)
  • ydevhub_key / ynetmon_key API anahtarları
  • GitHub OAuth erişim anahtarı (yalnızca yerel sync_auth.json içinde 0600 izniyle tutulur)
  • Ham ajan konuşma dosyaları (.jsonl / transcript)
